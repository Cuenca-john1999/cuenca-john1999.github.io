# Portfolio Profesional - Jhon M. Cuenca

Web profesional de presentación para Técnico Superior en Laboratorio Clínico y Biomédico.

## Características

- 🎨 Diseño minimalista e inspirado en Apple
- 🌍 Multilenguaje (Español, Inglés, Alemán)
- 🌓 Soporte para tema oscuro/claro
- 📱 Completamente responsivo
- ⚡ Sin frameworks, solo HTML5, CSS3 y JavaScript Vanilla
- 🏗️ Arquitectura modular y escalable

## Estructura del Proyecto

```
├── index.html           # Punto de entrada
├── css/                 # Estilos modulares
├── js/                  # JavaScript Vanilla
├── assets/              # Recursos gráficos
├── components/          # Componentes reutilizables
├── data/                # Datos (traducciones, etc.)
└── docs/                # Documentación
```

## Tecnologías

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- JavaScript Vanilla (ES6+)
- SVG

## Cómo Empezar

1. Clona o descarga el proyecto
2. Abre `index.html` en tu navegador
3. Comienza a desarrollar en `css/` y `js/`

## Documentación

Consulta la carpeta [docs/architecture](docs/architecture) para la documentación de arquitectura y [docs/decisions](docs/decisions) para las decisiones del proyecto.

## Desarrollo

El proyecto está estructurado de manera modular para facilitar el desarrollo y mantenimiento.

Antes de implementar cualquier funcionalidad:
1. Diseña la solución
2. Justifica las decisiones técnicas
3. Explica la arquitectura
4. Implementa el código
5. Revisa el resultado
